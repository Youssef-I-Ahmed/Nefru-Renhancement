# NEFRU API Documentation

Postman documentation for NEFRU backend APIs.

## Environment

Supported environments:

- Local Development
- Production

## API Modules

- Authentication
- Users
- Guides
- Trips
- Marketplace
- Bookings
- Payments
- Reviews
- Notifications
- Admin

## Authentication

Protected endpoints require:

Authorization: Bearer <JWT_TOKEN>

## Base URLs

Local:

http://localhost:5000/api

Production:

https://api.nefru.com/api
